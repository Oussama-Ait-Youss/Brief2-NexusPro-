# Nexus Front-End UI/UX Project

## 🧩 Contexte du projet

Ce projet a été réalisé dans le cadre d’un exercice pédagogique individuel visant à améliorer l’ergonomie et le design du site E-sport Nexus. L’objectif principal est de finaliser les maquettes UI/UX et d’intégrer les nouvelles pages web, en garantissant une navigation fluide, une performance optimale et une accessibilité multiplateforme.

---

## 🎯 Objectifs

- Finaliser et affiner les maquettes design des pages : `Properties`, `Blog`, `Contact`, `Event`, et `Tournament`.
- Intégrer les maquettes en code HTML5/CSS3 responsive.
- Optimiser les performances et l’accessibilité du site.
- Assurer la compatibilité entre navigateurs.
- Héberger le site sur GitHub Pages.

## 📱 Responsive Design

Le site est conçu pour s’adapter automatiquement aux tailles d’écran :
- Smartphones
- Tablettes
- Ordinateurs de bureau

Des Media Queries ont été utilisées pour garantir une expérience utilisateur optimale sur tous les appareils.

---

## ⚙️ Fonctionnalités clés

- Design cohérent avec la charte graphique de Nexus.
- Formulaire de contact accessible.
- Animations légères sur les éléments graphiques.
- Code modulaire selon les bonnes pratiques CSS (BEM).
- Structure sémantique HTML respectée (header, section, article, etc.).
- Optimisation des images pour un chargement rapide.
- Tests cross-navigateurs réalisés (Chrome, Firefox, Safari, Edge).
